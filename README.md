# 📊 Power BI Data Analysis Project

## 📌 Overview
This project presents an interactive data analysis dashboard built using Power BI. It focuses on transforming raw data into meaningful insights through visualization, data modeling, and calculated measures.

The dashboard enables users to explore trends, compare metrics, and make data-driven decisions efficiently.

---

## 🎯 Objectives
- Clean and transform raw dataset
- Build a structured data model
- Create meaningful measures (e.g., profit margin)
- Design interactive and user-friendly dashboards
- Extract actionable insights

---

## 🛠️ Tools & Technologies
- Power BI Desktop
- DAX (Data Analysis Expressions)
- Data Modeling Techniques

---

---

## 📊 Key Features
- Interactive visualizations
- Dynamic filtering and slicing
- Custom DAX measures
- Clean and intuitive UI design

---

## 📈 Example Metrics
- Total Sales
- Profit
- Profit Margin
- Category-wise Analysis
- Time-based Trends

---

## 🧠 Learning Outcomes
- Hands-on experience with Power BI
- Understanding of data relationships
- Writing DAX measures
- Designing dashboards for real-world use

---

## 🚀 How to Use
1. Download the `.pbix` file
2. Open it using Power BI Desktop
3. Explore dashboards using filters and visuals
